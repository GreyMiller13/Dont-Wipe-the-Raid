# Спецификация: локация «Мрачное подземелье» — сегменты для бесшовной склейки

Дата: 2026-11-17 · v2 от 2026-11-18 · Статус: конвенция утверждена; промпты переведены на референсный формат (после брака безреференсной генерации — папка segments2 удалена как некондиция по решению пользователя)

Назначение: единая система координат, палитра и правила композиции для всех сегментов локации, чтобы при склейке получалась одна непрерывная картинка. Конвенция обязательна для всех промптов; отступления запрещены. Эта же структура ляжет в основу других локаций (замок, пещера и т.д.) — меняться будет палитра и набор декора.

**Принцип v2 (ключевой):** генерация ведётся «от референса»: короткий прицельный промпт правок к конкретному файлу-эталону. Два сегмента не генерируются вообще — используются готовые эталоны. Промпты переносимы: подходят для любой модели генерации (текст + файл референса).

## 1. Общая конвенция (остаётся стандартом проверки)

### 1.1. Геометрия кадра

| Параметр | Значение (доля высоты кадра) | Комментарий |
|---|---|---|
| Потолочная зона | 0–10% | тёмный камень потолка, ровная нижняя кромка на 10% |
| Задняя стена | 10–80% | строго фронтальная, параллельна экрану, без перспективы |
| Полоса пола | 80–100% | линия пола — всегда на 80% |
| Рост героя | ~31% кадра | высота зала ≈ 2,25 роста героя |
| Формат кадра | 16:9, 2816×1584 | ландшафтный |

Правила: одна плоскость пола (80%) и потолка (10%); никакой перспективы вглубь, боковых стен, углов; виньетка и затемнение краёв запрещены.

### 1.2. Паттерны (едины во всех сегментах)

- **Кладка стены:** крупные прямоугольные блоки ~9% кадра высотой, ровные горизонтальные ряды со смещением на полблока, тонкие тёмные швы.
- **Пол:** крупные квадратные плиты одинакового размера, ровное мощение, тёмные швы.
- **Пилястры/арки:** только заподлицо со стеной (плоский рельеф), никаких объектов переднего плана.
- **Факелы:** центр пламени на 40% высоты кадра; шаг ~1 факел на сегмент.
- **Освещение:** ровное тёплое, читаемое; холодный свет — только у проёмов входа/выхода.

### 1.3. Палитра (HEX-ориентиры)

Камень: #4A4238/#3A332B; швы #2A251F; потолок #2E2922; пол #55493C, швы пола #2F2820; мох #5C6B3A; дерево #6B4E2E; ржавый металл #6E5A44; пламя #FF9A3C с ядром #FFD27A; свет проёмов #9FC7E8.

### 1.4. Правила краёв и декора

- 12% ширины у каждого края — только однородная стена с непрерывной кладкой (исключения: проём входа S1 прижат к левому краю, проём выхода S6 — к правому).
- Все объекты целиком внутри кадра с отступом ≥12% от краёв; краем не обрезается ничего, кроме стены.
- Персонажи/монстры в фон не запекаются.

## 2. Карта уровня (порядок склейки)

```
[S1 вход] → [6 боевых комнат из S2–S5 в случайном порядке без дублей подряд] → [S6 арена босса]
```

Текущая сборка (seed 42): `S1 → S4 → S3 → S2 → S5 → S2 → S3 → S6` (8 сегментов). Число боевых комнат настраивается (6 по умолчанию, ориентир 20–30 врагов на локацию).

**Производственная конвенция (реализована в scripts/uniform_floor2.py):** пол НЕ живёт в слайдах. Стена каждого сегмента обрезается на 73% высоты кадра (выше любой линии пола слайдов), ниже крепится единая плашка «нижний ряд кладки + пол» из S2 — отдельный ассет `assets/prototypes/locations/dungeon-floor-tile.jpg` (2752×415). В движке: стена скроллится сегментами, пол — один повторяемый bitmap-слой.

**Урок 2026-11-18 (обязателен к исполнению): послойная архитектура фона.**
Слои снизу вверх: (1) стена — сегменты; (2) пол — один тайл, повторяемый (не растягиваемый; период плитки подбирается автокорреляцией, скрипт `uniform_floor4.py`); (3) **декор — отдельные спрайты поверх пола** (черепа, кости, бочка, ящик, лужица, паутина), раскладываются в любых точках и НЕ запекаются в слайды фона — иначе срез пола уничтожает декор (ошибка v7, найдена пользователем); (4) персонажи/монстры; (5) эффекты.

**Стандарт слайдов v3 (2026-11-18): слайды генерируются БЕЗ ПОЛА.** Слайд — только стена: нижний край кадра проходит ровно по линии примыкания пола к стене, полосы пола в кадре нет вообще (модель дорисовывает пол — это брак). Пол — отдельный тайл (`floor.jpg` в папке набора), подкладывается под все слайды при сборке единым слоем. Декор — только на стене, выше нижнего края кадра. Референс-слайды: `assets/prototypes/locations/segments/S1..S6.jpg` (стиль), генерация — пользователем во внешней ИИ по промптам из приложения A.

| Сегмент | Источник | Референс для генерации |

Состав по сегментам (как утверждено): S1 — арочный проём-спуск слева, факел на 60% ширины, черепа у плинтуса; S2 — стена, две мелкие трещины (30%/70%), факел в центре; S3 — две пилястры (30%/70%), факел в центре; S4 — решётка (30%), бочка+ящик (55–65%), кости (40%), паутина, факел (80%); S5 — мох у пола (25–45% и 70–85%), потёк (60%), лужица (75%), факел в центре; S6 — проём-выход справа, трофеи (30–40%), черепа (15%), факелы (20% и 55%).

## 4. Чек-лист непротиворечивости

| # | Проверка | Статус |
|---|---|---|
| 1 | Линия пола на 80% кадра во всех сегментах | ✅ S2/S6 — эталоны с проверенной плоской геометрией; S1/S3/S4/S5 генерируются от референсов S2/entrance-v2 с требованием «пол не трогать» |
| 2 | Линия потолка на 10% | ✅ аналогично |
| 3 | Кладка/пол — один паттерн | ✅ все генерации от одного эталона base.jpg |
| 4 | Пламя факела на 40% высоты | ✅ фиксируется в каждом промпте как «не трогать» |
| 5 | Зоны стыка 12% без объектов (кроме проёмов S1/S6) | ✅ в промптах: декор в диапазоне 25–80% ширины |
| 6 | Проёмы входа/выхода зеркально симметричны | ✅ S1 генерируется от entrance-v2 (проём у левого края), S6 готов (проём у правого края) |
| 7 | Без объектов переднего плана | ✅ S3 — пилястры заподлицо |
| 8 | Палитра одна | ✅ референсный подход наследует палитру эталона |
| 9 | Виньетка запрещена | ✅ в каждом промпте |
| 10 | Персонажи не запекаются | ✅ в каждом промпте |
| 11 | Взаимозаменяемость S2–S5 | ✅ все края — однородная стена эталонного паттерна |

Остаточный риск: референсный подход переносит геометрию эталона, но модель может «уплести» правку в кладку/пол — поэтому после генерации каждый файл проверяется по чек-листу (пол 80%, факел 40%, чистые края) и битые перегенерируются точечно тем же промптом.

## Приложение A — промпты (референсный формат, v2)

Формат: файл референса прикладывается к запросу; текст ниже — полный промпт. Промпты самодостаточны и переносимы на любую модель.

**S1 — вход (спуск в подземелье)** · референс: `segments/dungeon-seg-entrance-v2.jpg`

> Пиксель-арт 16-bit. Возьми референс и внеси ровно одну правку: старую деревянную дверь в левой части замени на каменный арочный проём, из которого вниз к уровню пола спускается каменная лестница (ступени идут сверху-слева вниз-вправо и выходят на пол); в глубине проёма — холодный голубоватый свет (#9FC7E8), как вход спуска из верхнего мира. Всё остальное сохрани без изменений: линию пола и потолка, кладку и паттерн плит пола, факел на прежнем месте и высоте, тон и палитру, ровное тёплое освещение без виньетки. Правые 12% кадра — глухая стена с непрерывной кладкой. Строго боковой вид, плоская стена, без перспективы, без персонажей, без текста.

**S3 — пилястры** · референс: `segments/dungeon-seg-base.jpg`

> Пиксель-арт 16-bit. Возьми референс и добавь две каменные пилястры заподлицо со стеной — плоские вертикальные выступы стены шириной около 6% ширины кадра, с капителью у потолка и базой у линии пола, на 30% и 70% ширины кадра. Пилястры — часть стены, НЕ передний план, из глубины сцены не выступают. Всё остальное сохрани без изменений: линию пола и потолка, кладку и плиты пола, факел в центре на прежней высоте, палитру и освещение без виньетки. Крайние 12% ширины с обеих сторон — только глухая стена. Строго боковой вид, плоская стена, без перспективы, без персонажей, без текста.

**S4 — интерьер** · референс: `segments/dungeon-seg-base.jpg`

> Пиксель-арт 16-bit. Возьми референс и добавь пристеночный декор: ржавую железную решётку-вентиляцию в кладке стены на 30% ширины кадра; старую деревянную бочку и сломанный ящик у плинтуса на 55–65% ширины; кучку костей у плинтуса на 40% ширины; немного паутины в верхнем углу над решёткой. Все объекты стоят у стены, НЕ передний план. Всё остальное сохрани без изменений: линию пола и потолка, кладку и плиты пола, палитру и ровное тёплое освещение без виньетки. Крайние 12% ширины с обеих сторон — только глухая стена. Строго боковой вид, плоская стена, без перспективы, без персонажей, без текста.

**S5 — стена с мхом и водой** · референс: `segments/dungeon-seg-base.jpg`

> Пиксель-арт 16-bit. Возьми референс и добавь сырость: обширные пятна зелёного мха (#5C6B3A) у линии пола на 25–45% и 70–85% ширины кадра; тонкий влажный тёмный потёк от шва кладки вниз на 60% ширины; небольшую лужицу у линии пола на 75% ширины. Всё остальное сохрани без изменений: линию пола и потолка, кладку и плиты пола, факел в центре на прежней высоте, палитру и ровное тёплое освещение без виньетки. Крайние 12% ширины с обеих сторон — только глухая стена. Строго боковой вид, плоская стена, без перспективы, без персонажей, без текста.
