# Спецификация MVP-среза «Don't Wipe the Raid»

Дата: 2026-11-18 · Статус: черновик v1 на утверждении
Основание: `docs/vision.md` v0.3, ADR-0002. Все балансные числа — стартовые, правятся на плейтесте без изменения механик.

## 1. Область

Браузерный прототип (HTML5 Canvas, чистый JS, file://), одна локация «Мрачное подземелье», полный цикл: **новая игра → забегы (бой, лут, прокачка) → первое победа над боссом → повторные забеги**. Цель — валидировать петлю «забег → лут → прокачка → глубже» и боевую механику. Всё вне разделов 2–11 — пост-MVP (раздел 12).

## 2. Экраны и навигация

| Экран | Содержимое |
|---|---|
| **Главное меню** | Название-заглушка; кнопки «Новая игра», «Продолжить» (недоступна без сейва), «Настройки». «Новая игра» при существующем прогрессе — предупреждение о перезаписи (подтверждение). |
| **Настройки** | Ползунки «Музыка» и «Звук» (каркас: значения сохраняются, звукового контента в MVP нет); кнопка «Назад». |
| **Выбор локации** | Карточка локации №1 «Мрачное подземелье»; справа — 2 карточки будущих локаций (затемнены, «?», не листаются дальше). Бейдж «Пройдена» после первой победы. Кнопки: **«В бой»**, **«Прокачка»**, **«Панель навыков»**. |
| **Прокачка** | Три вкладки-дерева (воин / жрица / лучник), см. раздел 7. Баланс монет виден. |
| **Панель навыков** | Редактор 5 слотов; библиотека доступных скиллов и зелья; сохранить. Только здесь панель меняется. |
| **Забег** | Сцена комнаты; сверху легенда-карта; внизу панель навыков; в углу бургер-меню. |
| **Итоги забега** | Причина (победа / вайп / отступление); заработанное: монеты, зелья (подобранное); кнопка «К выбору локаций». |

Возврат в главное меню — из экрана выбора локаций (кнопка «Меню»).

## 3. Цикл забега

1. **Вход:** fade-in (~0.7 с) — партия стоит у входа, дверь за спиной (слева). Комната пуста, горит стрелка-указатель справа.
2. **Переход:** тап по стрелке → герои идут вправо → fade-out → fade-in в следующей комнате (герои у левого края).
3. **Комнаты боевые:** 5 комнат, враги появляются сразу при входе (стоят справа; часть может вбежать в первые ~1 с). Состав: 2 / 2 / 3 / 3 / 4 врага (микс гоблин-воин / гоблин-лучник, доля лучников растёт к 5-й комнате).
4. **Комната босса:** 6-я комната, гоблин-король.
5. **Комната сундука:** только при первом убийстве босса данной локации: 7-я комната, сундук по центру. Тап по сундуку → анимация открытия, россыпь монет и 2 зелий → подбор (раздел 8). Затем стрелка → итоги (победа). При повторных прохождениях комната не генерируется: после босса сразу стрелка → итоги.
6. **Завершение забега:** победа (уход после сундука/босса), вайп (смерть всех троих) или отступление (бургер-меню → «Отступить» → подтверждение; доступно в любой момент, включая бой). Во всех случаях подобранный лут сохраняется; неподобранный (лежащий в комнате) пропадает. После забега все герои живы с полным HP.
7. **Легенда-карта** (верх экрана, всегда в забеге): `[вход] • • • • • [босс] [сундук]` — точки комнат; пройденные затемнены, текущая подсвечена, справа метка сундука. Без иконки черепа.

## 4. Боевая модель

**Позиции (side-view, слева направо):** лучник (~15% ширины) → жрица (~25%) → воин (~35%); враги в правой половине (~65–95%). Герои не перекрываются; сцена вмещает до 4 врагов без наложения.

**Автоатаки:** каждый герой автоматически атакует **ближайшего к нему живого монстра** (по X). Ближний бьёт ближнего, задний герой чаще достаёт задних врагов — это и создаёт потребность в прицельных навыках.

**Монстры** атакуют **переднего живого героя** в порядке воин → жрица → лучник. Гоблин-лучник бьёт с дистанции того же переднего (монстры, бьющие задних, — пост-MVP).

**Активные действия игрока (единственная механика активации):**
- **Прицельный навык** (мощный удар, меткий выстрел): зажать ЛКМ на слоте → курсор на монстре — монстр подсвечивается (рамка/тонировка; подсветка следует за курсором, снимается при уходе) → отпустить ЛКМ на монстре = применено (если хватает ресурса). Отпустил мимо / на недоступной цели — навык не потрачен, слот возвращается.
- **Зелье:** аналогично, цель — герой; подсветка героя при наведении. Применение на героя с полным HP запрещено (зелье не тратится, красная индикация).
- **Мгновенный навык (мультивыстрел):** тап по слоту — применяется сразу веером, без прицеливания: до 3 передних живых целей; если живых меньше 3 — по всем оставшимся.
- **Фаербол (режим):** тап по слоту переключает вкл/выкл. Вкл — жрица вместо лечения кастует фаерболы (каждый каст тратит ману). Мана на нуле — касты невозможны, жрица автоматически лечит; при восстановлении ≥ стоимости каста атаки возобновляются (режим остаётся включённым). **Индикация режимов вкл/выкл:** активный слот-переключатель обведён золотистым «бегущим» пунктиром, анимированным по часовой стрелке; при выключении подсветка гаснет.
- Скилл, не выложенный на панель, применён быть не может.

**Смерть:** герой с 0 HP падает и не действует до конца забега (лечение не воскрешает). Урон монстров переходит следующему живому по порядку. Вайп — смерть всех трёх → итоги.

**Ресурсы (обнуляются при старте каждого забега):**

| Ресурс | Владелец | Получение | Расход |
|---|---|---|---|
| Ярость (0–100) | воин | +25 за убийство монстра любым героем; +2/с, только пока идёт бой | блок 40, мощный удар 50 |
| Фокус (0–100) | лучник | +25 за убийство; +2/с, только в бою | мультивыстрел 40, меткий выстрел 60 |
| Мана (0–20, старт 0 до открытия) | жрица | +1 каждые 2 с, только пока идёт бой | фаербол 3/каст |

Между комнатами (вне боя) ярость/фокус/мана не восстанавливаются — ждать восстановление негде и незачем.

**Пауза/скорость боя** — пост-MVP; бой идёт своим темпом.

## 5. Герои

| Герой | Старт | Из дерева прокачки |
|---|---|---|
| **Воин (человек, щит+меч; рост как у жрицы и лучника)** | автоатака мечом 8 урона / 1.5 с; HP 120 | блок: −75% входящего урона на 3 с (активный, ярость); мощный удар: 40 урона в выбранную цель (ярость, прицельный); прокачка урона/HP |
| **Жрица (женщина с посохом)** | без атаки; авто-лечение: 25 HP самому раненому (по % потерянного) с HP < 70%, кулдаун 8 с; HP 80 | мана + фаербол-режим (20 урона / каст); прокачка силы лечения, пула маны, регена маны; ветка зелий (шанс дропа, сила зелья) |
| **Лучник (эльф, капюшон)** | автоатука стрелой 6 урона / 1.2 с; HP 70 | мультивыстрел: веер 3 стрел по 8 урона — до 3 передних живых целей, меньше — по всем (фокус, тап); меткий выстрел: 50 урона в выбранную цель (фокус, прицельный); прокачка урона/скорости атаки |

Визуально кодовые персонажи отражают состояние: полоски HP/ресурсов, частота взмахов = скорость атаки, потеря HP/смерть — позой/затемнением.

## 6. Монстры локации №1

Сила растёт по комнатам: множитель m = 1 + 0.15·(№комнаты − 1) (комната 5 → ×1.6).

| Монстр | HP | Урон | Интервал | Особенность |
|---|---|---|---|---|
| Гоблин-воин | 30·m | 6·m | 1.8 с | ближний бой |
| Гоблин-лучник | 20·m | 5·m | 2.0 с | дальний, стоит позади воинов |
| **Гоблин-король (босс)** | 350 | 18 | 2.2 с | тот же гоблин ×1.8 размером, корона/плащ; раз в 12 с усиленный удар ×2 |

## 7. Дерево прокачки

Три отдельных дерева; каждое состоит из независимых ветвей (первый узел каждой ветки доступен сразу, порядок узлов внутри ветки — сверху вниз). **Постепенное открытие:** в ветке виден доступный к покупке узел + следующий за ним (заблокирован); глубже — заглушки «?». Следующий узел открывается покупкой предыдущего. Купленное — навсегда. Цены растут с каждой покупкой узла (множитель ×1.25 для длинных, ×1.3 для коротких, указаны базовые). Монеты — единственная валюта.

**Воин:**
- *Искусство боя:* **Мощный удар** (**15**, ×1 — дёшево и рано: первый активный скилл игрока) → **Блок** (40, ×1) → длительность блока +1 с (база 25, ×3, макс 6 с)
- *Сила:* урон автоатаки +2 (база 12, ×10)
- *Стойкость:* HP +15 (база 10, ×10)

**Жрица:**
- *Свет:* сила лечения +8 (база 10, ×10)
- *Магия:* **Фаербол и мана** (60, ×1 — открывает ману 20 и режим атаки) → мана +10 (база 20, ×5) → реген маны −0.5 с к тику (база 25, ×3)
- *Зелья:* Зельеварение: +5% к шансу выпадения зелий (база 15, ×3) → Крепкие зелья: +20 HP к лечению зельем (база 30, ×3)

**Лучник:**
- *Стрельба:* урон +1.5 (база 12, ×10)
- *Ловкость:* скорость атаки −10% интервала (база 18, ×10)
- *Приёмы:* **Мультивыстрел** (50, ×1) → **Меткий выстрел** (70, ×1)

После покупки активного навыка он появляется в библиотеке редактора панели.

## 8. Лут и экономика

- **Монеты:** гоблин 4 шт., босс 40, сундук 60. Вылетают из монстра россыпью (2–4 физические монеты), падают на пол.
- **Зелья:** базовый шанс выпадения с гоблина 10%, +5% за уровень узла «Зельеварение» (до 25%); сундук — ровно 2. Зелье лечения: +40 HP одному герою, +20 за уровень «Крепких зелий».
- **Подбор:** наведение курсора (hover) на предмет — предмет летит к счётчику HUD и зачисляется. На тач (порт) — касание.
- **Зелья в панели:** слот «Зелье лечения» выкладывается в редакторе панели и показывает текущий запас; подбор зелья увеличивает запас. Если слот не выложен, а во время забега зелье подобрано и в панели есть свободный слот — создаётся **временный слот зелья** до конца забега (после забега панель возвращается к настроенному виду, запас сохраняется). Если свободного слота нет — зелье остаётся лежать на полу.
- **Зелье с пола:** лежащее зелье можно применить напрямую, минуя панель: зажать ЛКМ на зелье → навести на героя (подсветка) → отпустить ЛКМ — лечение применено, зелье исчезает. Работает и с выложенным слотом, и без него.
- **Подобранное** суммируется в итогах забега и зачисляется при любом исходе (вайп включительно). **Неподобранное** остаётся лежать в комнате до конца забега; при завершении (вайп/победа/отступление) в зачёт не попадает.
- **Ожидаемая экономика:** полное первое прохождение ≈ 156 монет (14 гоблинов + босс + сундук); ранний вайп на 3–4 комнате ≈ 25–45. Первые покупки (мощный удар 15, урон/HP 10–12) доступны после 1–2 забегов — петля сразу оживает.

## 9. Сохранение и настройки

- Автосейв (localStorage) после: завершения забега, покупки узла, изменения панели/настроек. «Продолжить» восстанавливает: прогресс локаций, купленные узлы, панель, запас зелий, монеты, настройки.
- «Новая игра» сбрасывает всё (с предупреждением).
- Настройки музыки/звука хранятся; контент — пост-MVP.

## 10. Нефункциональные требования

- Canvas 1280×720, ландшафт, масштабирование под окно с сохранением пропорций; ввод — мышь.
- Запуск с file://, без зависимостей и сборщиков; чистый JS (ES-модули по экранам допустимы).
- **Архитектура:** симуляция (правила, данные, тик боя) отделена от рендера; все балансные числа — в одном конфиге. Рендер персонажей послойный (тело → экипировка → эффекты) — задел под смену экипировки (пост-MVP).
- Интерфейс — русский.
- Плавность: 60 FPS целевых, на сцене ≤ 10 активных сущностей.

## 11. Критерии готовности MVP (проверяемые)

1. Полный путь с нуля: меню → локация → 5 комнат → босс → сундук → итоги «победа»; и путь вайпа → итоги с сохранением подобранного.
2. Ранний вайп (1–3 забег) → покупка «Мощный удар» и минимум одного стат-узла → заметное продвижение в следующем забеге.
3. Прицельные навыки: подсветка цели при наведении, применение по отпусканию ЛКМ, возврат без траты при промахе; зелье — на героя, запрет при полном HP; мультивыстрел тапом — до 3 передних целей (меньше — по всем).
4. Фаербол-режим: вкл/выкл тапом; активный режим виден золотистым «бегущим» пунктиром рамки слота (по часовой стрелке), при выключении гаснет; атаки тратят ману по 3; при 0 маны жрица лечит, при восстановлении — возобновляет касты.
5. Ярость/фокус: растут от убийств и только в бою; вне боя замирают; обнуляются на старте забега.
6. Смерть героя — до конца забега; урон монстров переходит следующему живому; вайп = смерть всех.
7. Отступление из бургер-меню в любой момент (в т.ч. в бою), с подтверждением; лут сохраняется.
8. Сундук и комната сундука — только при первом прохождении; повторный забег после босса сразу к итогам.
9. Легенда-карта корректно отражает позицию; сундук как конечная метка.
10. Автосейв/«Продолжить» после закрытия браузера восстанавливает прогресс.
11. Все узлы деревьев покупаются и применяют эффекты в бою (числа — из конфига).
12. Подбор hover: монета/зелье зачисляются при наведении; при невыгруженном слоте зелья и свободном слоте панели появляется временный слот зелья (исчезает после забега); лежащее зелье применимо drag-n-drop с пола на героя; неподобранное при завершении забега в зачёт не попадает.

## 12. Вне скоупа (пост-MVP)

Звук и музыка (контент) · экипировка · монстры, бьющие задних · масс-исцеление · расширение панели навыков · локации 2–10, новые типы монстров · престиж, оффлайн-прогресс · пауза/скорость боя · тач-ввод и Android-порт (решение после MVP) · полировка визуала/арт-генерация.
