# Vision: Don't Wipe the Raid (рабочее название)

Дата: 2026-11-17 · Актуализировано: 2026-11-18 · Статус: v0.3 — переработан после рестарта проекта; детализация MVP-среза вынесена в `docs/specs/mvp-slice.md`

## Проблема

Для автора: нет практического опыта мобильной разработки — цель освоить полный цикл (от требований до работающего продукта) на собственном проекте, а не учебном примере.

Для игрока (предположение, не валидировано): в жанре инкрементальных партийных RPG почти все живые примеры — F2P с гачей, таймгейтами и давлением монетизации (AFK Arena, Idle Champions); «честных» компактных данжен-инкременталок уровня Soda Dungeon 2 / Loop Hero мало, и они устаревают или останавливаются в развитии.

## Целевая аудитория

1. **Автор проекта** — первый пользователь и критик; системный аналитик, играет в инкременталки; ценит видимый прогресс и понятные механики.
2. **Игроки инкрементальных/idle-RPG** — знакомы с жанром, хотят партийную данжен-прогрессию короткими сессиями без обязательной монетизации.
3. **Просмотр портфолио** (потенциально) — проект демонстрирует полный цикл product discovery → работающая игра.

## Ценность и отличие

Игрок ведёт группу из 3 героев (воин/жрица/лучник) по подземельям с волнами монстров и боссом; после вайпов заработанные ресурсы вкладываются в деревья навыков каждого героя, открывая следующие локации из 10. Отличие от аналогов: без гачи и пейволов, риск-петля забега вместо таймгейтов, компактная читаемая прокачка вместо 5 параллельных треков (основано на конкурентном анализе, `docs/research/competitive-analysis.md`).

Петля игры: **забег → подбор лута (осознанный) → вайп/победа/отступление → прокачка → забег глубже**. Активные способности и зелья требуют прицельного применения игроком — бой автоматический, но не пассивный.

## Цели и метрики успеха

| Цель | Метрика | Целевое значение | К когда |
|---|---|---|---|
| Работающий браузерный прототип | Играется в браузере без сервера (file://) | да | MVP |
| Играбельный сквозной сценарий | Старт → забег → смерть/победа → прокачка → босс локации 1 без блокеров | да | MVP |
| Полный контент vision-версии | 10 локаций проходимы; прогресс сохраняется между сессиями | да | пост-MVP |
| Короткая сессия | Забег до смерти/босса укладывается в 2–5 минут | да | MVP |
| Ощутимый прогресс | За сессию 15–20 мин доступна минимум одна новая покупка/уровень навыка | да | MVP |
| Решение о платформе | По итогам MVP принято: Android-порт / веб / оба | да | после MVP |

## Границы

**Не-цели (MVP, см. спеку):**
- Монетизация, реклама, IAP.
- Онлайн: мультиплеер, серверная часть, аккаунты, облачные сохранения (прогресс — локально).
- 4-й и последующие персонажи, смена состава партии.
- Звук и музыка (UI настроек — каркас, контент позже).
- Экипировка (послойная структура кодовых персонажей под неё закладывается).
- Монстры, атакующие задних героев; масс-исцеление; расширение панели навыков.
- Локализации: один язык — русский.

**Анти-цели:**
- Гача, лутбоксы, пейволл, таймгейты на уже заработанные награды.
- Конфискация прогресса при смерти группы (жанрово провалено): подобранный лут сохраняется всегда.
- Числа сложнее ~e12 — теряется читаемость и возможность балансировки.

## Ограничения

- Время автора: 4–8 ч/нед, ситуативно; при высокой рабочей нагрузке паузы.
- Платформа разработки: **браузерный прототип** (HTML5 Canvas, без зависимостей) — ADR-0002; ADR-0001 (Kotlin + Compose) заморожен до решения об Android-порте по итогам MVP.
- Один разработчик без художника: визуал строится на **кодовой отрисовке персонажей** (см. решения), фоны — простые программные сцены; генерация арта пакетно в конце, если понадобится.

## Риски (топ-3)

| Риск | Как обнаружим | Реакция |
|---|---|---|
| Раздувание скоупа при 4–8 ч/нед — MVP не сходится | спека MVP не закрыта за запланированные рабочие окна | жёсткий скоуп `specs/mvp-slice.md`; всё вне списка — пост-MVP |
| Дисбаланс экономики: стены непроходимы или проходятся без прокачки | локация проходится без покупок / застревание >3 забегов без прогресса | стартовая балансная таблица в спеке + симуляция/плейтест; правка чисел, не механик |
| Кодовый визуал «не тянет» целевой уровень | после MVP визуальная часть выглядит сыро при работающих механиках | пакетная арт-стадия в конце (генерация/ассеты поверх послойной структуры); механики к этому моменту валидированы |

## Решения по дизайну

Сводка решений v0.3 (2026-11-18, обсуждение рестарта); детализация — в `docs/specs/mvp-slice.md`.

### Оболочка и сессия

1. **Экраны:** главное меню (новая игра / продолжить / настройки) → выбор локаций (листание, дальше пройденной нельзя) с разделами прокачки и редактирования панели навыков → забег → итоги забега.
2. **Забег = комнаты с fade-переходами:** бой на экране → стрелка-указатель → движение к ней → затемнение → fade-in в новой комнате. Непрерывная склейка-панорама отменена (подход забракован 2026-11-18).
3. **Вход в локацию:** плавное появление партии у входа (дверь за спиной), без анимации дверей.
4. **Легенда-карта** сверху экрана: текущая позиция и остаток пути до сундука (без иконки босса).
5. **Отступление:** кнопка-бургер в углу → меню → «Отступить» с подтверждением; доступно в любой момент, включая бой; подобранный лут сохраняется.
6. **Прокачка и редактирование панели — только с экрана выбора локаций**; во время забега недоступны.
7. **Сундук — комната после босса, только при первом прохождении локации**; повторные забеги без сундука. Без лестницы/выхода за боссом.
8. **Лут подборный:** из монстров и сундука вылетают монеты/зелья; подбор — наведением курсора. Неподобранное при завершении забега пропадает, подобранное сохраняется всегда (даже при вайпе).

### Бой

9. **Бой автоматический** (автоатаки), активные способности применяет игрок.
10. **Таргетинг автоатак:** каждый герой бьёт ближайшего к нему монстра. Точечные атакующие навыки — **прицельные**: зажать навык на панели → навести на монстра (подсветка) → отпустить = удар. Единая механика прицеливания: зелья — на героев, навыки — на монстров. Цель — возможность фокусить задних (лучники/маги монстров).
11. **Позиции партии:** воин впереди, за ним жрица, в тылу лучник. Монстры бьют переднего живого героя; после смерти воина урон переходит следующему по порядку. Монстры, бьющие задних, — пост-MVP.
12. **Смерть героя — до конца забега** (не воскрешается лечением); забег продолжается, пока жив хоть один герой; после забега все оживают.
13. **Персонажи отрисовываются кодом — целевое решение:** слои (тело, экипировка), визуально видимые скорость атаки и урон; пиксель-арт спрайты героев отменены (v0.2, решение №6).

### Герои и ресурсы

14. **Воин:** старт — только автоатака мечом. Из дерева: блок (−урон на время, активный) и мощный удар (точечный). Ресурс **ярость**: копится за убийства (много) и медленно в бою; вне боя не растёт — нельзя «отстоять» ресурс между комнатами.
15. **Жрица:** старт — без атаки вовсе, только авто-лечение (малое, большой кулдаун) — обеспечивает выживание. Из дерева: мана, фаербол (режим атаки: каждая атака тратит ману; кончилась — снова только лечит) и масс-исцеление (пост-MVP). Мана восстанавливается со временем.
16. **Лучник:** старт — одиночная слабая стрела. Из дерева: скорость атаки, урон, мультивыстрел (веер), меткий выстрел (точечный). Ресурс **фокус** — механика ярости: убийства + медленный реген в бою.
17. **Панель навыков: 5 слотов** на старте; выкладываются активные навыки и предметы (зелья). Расширение слотов — пост-MVP (какая ветка — открытый вопрос).

### Прокачка и монстры

18. **Три отдельных дерева навыков**; постепенное открытие: виден доступный узел + следующий, глубже — заглушки. Купленное — навсегда.
19. **Цены растут с каждой покупкой**; узлы трёх типов: одноразовые, ограниченные (~3), длинные (~10).
20. **Монстры растут по силе** внутри локации и между локациями. Один тип используется как обычный и как босс (тот же монстр крупнее + иной визуал) — отдельных босс-спрайтов нет.
21. **Локации тематические** (подземелье, склеп, пещера, замок, руины), различие — в первую очередь палитра/набор фонов; MVP — одна локация «Мрачное подземелье».
22. **Ориентация ландшафтная**, панель навыков внизу, легенда-карта сверху. Перспектива 2D side-view: герои идут слева направо, монстры справа, без разворотов к камере.

## Открытые вопросы

1. Ветка/условия расширения панели навыков за 5 слотов (пост-MVP).
2. Условия восстановления активных навыков — закрыто решениями 14–16 (ярость/фокус/мана); осталось: числа баланса.
3. Название и сеттинг (рабочее — «Don't Wipe the Raid»).
4. Оффлайн-прогресс (по умолчанию для MVP — нет).
5. После MVP: Android-порт (нативный/WebView/PWA) или веб — решение по итогам прототипа.
6. Экипировка как система (когда и как влияет; структура под неё уже закладывается).
